# Expense Tracker

## Project Overview
Expense Tracker is a desktop application developed using Python and Tkinter. It helps users manage their income and expenses and keep track of their balance.

## Features
- Add income and expenses.
- View total income.
- View total expenses.
- Check available balance.
- Record transaction dates and categories.

## Technologies Used
- Python
- Tkinter

## How to Run
1. Install Python.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run the following command:

```bash
py ExpenseTracker.py
```

## Objective
To make it easier to record and manage daily income and expenses.
